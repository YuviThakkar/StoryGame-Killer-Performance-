# StoryGame: Killer Performance

This is the first ever full Python game I made, under my overall project "StoryGame". It is an adaptation of my friend's personal fiction story into an interactive text game. It includes area exploration (built from while loops), dialogue/action choices (built from if/elif/else branches), collectibles (built from global variables) and more. It took me awhile to finish as I lost motivation but eventually found it back and pushed to the finish line, featuring 396,216 possible ending score cards. As of now I plan to make many more StoryGames in the future and hope to improve my storytelling and programming skills with each one!
